## 2. Mejoras de Generación y Validación en P1.4

1. **Separación de Generación y Validación:**
   - Validación: `node scripts/generate-sbom.js --validate`
   - Generación: `node scripts/generate-sbom.js --tarball <path> --output <path>`
2. **Protección de Artefactos Históricos:** Si el archivo SBOM de destino ya existe, el script aborta con error de preservación a menos que se especifique `--force`.
3. **Bandera `--generate-if-missing` para CI:** Permite empaquetar y generar el SBOM en entornos de integración continua efímeros donde los artefactos no están versionados en Git.
4. **Validación Profunda del Grafo de Dependencias:** Se verifica que ninguna relación `dependsOn` apunte a un componente no registrado en la lista de componentes.

## 3. Limitaciones Documentadas de Reproducibilidad

El repositorio de OpenMemory no versiona un archivo `package-lock.json`, siguiendo la convención estándar de bibliotecas npm para permitir la resolución flexible en consumidores.
- **Implicación:** La resolución de dependencias transitivas durante un `npm install` fresco depende de las versiones disponibles en el registro npm en el momento de la instalación, salvo que el consumidor fije un lockfile propio.
- **Mitigación:** El SBOM CycloneDX generado registra las versiones exactas resueltas en el entorno de release, permitiendo auditorías forenses precisas de vulnerabilidades.
