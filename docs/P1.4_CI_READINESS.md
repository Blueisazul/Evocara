# P1.4 Multiplatform CI & Workflow Audit

**Documento:** Auditoría de CI y Compatibilidad Multiplataforma  
**Workflow:** `.github/workflows/ci.yml`  
**Iteración:** P1.4  

---

## 1. Matriz de Ejecución Declarada

El archivo de workflow define 9 combinaciones en matriz (`fail-fast: false`):
- **Sistemas Operativos:** `ubuntu-latest`, `macos-latest`, `windows-latest`
- **Versiones de Node.js:** `18.x`, `20.x`, `22.x`

---

## 2. Configuración de Seguridad y Permisos del Workflow

- **Permisos:** `contents: read` (mínimos privilegios requeridos).
- **Concurrencia:** `group: ${{ github.workflow }}-${{ github.ref }}`, `cancel-in-progress: true`.
- **Estrategia de Instalación:** Detecta si existe `package-lock.json` para usar `npm ci`, o realiza `npm install` limpio.
- **Compilación TypeScript:** `npm run build` (`tsc`).
- **Ejecución de Pruebas:** `npm run test:safe` (ejecuta las 13 suites registradas).
- **Verificación de Empaquetado:** `node scripts/ci-verify-package.js` (6 comprobaciones, incluyendo instalación y runtime en sandbox sintético).
- **Generación y Validación de SBOM:** `node scripts/generate-sbom.js --generate-if-missing && node scripts/generate-sbom.js --validate`.
- **Captura Forense de Evidencia:** En caso de fallo, se recopilan automáticamente `.work/evidence/`, `*.log` y `promotion_abort_evidence.json` mediante `actions/upload-artifact@v4`.

---
