## 4. Limitaciones Documentadas de Completitud
* **Ausencia de Lockfile en Git:** Al ser una biblioteca npm que no versiona `package-lock.json`, las versiones transitivas corresponden al árbol instalado en el entorno de desarrollo actual. En futuras compilaciones en entornos limpios, el SBOM debe regenerarse para reflejar las versiones exactas resueltas.
* **Atestación de Procedencia (SLSA):** El SBOM documenta la composición del software, pero no sustituye una atestación de compilación hermética (SLSA Level 3) ni firmas criptográficas de release (e.g., Cosign/Sigstore), las cuales corresponden a la fase de publicación remota.
