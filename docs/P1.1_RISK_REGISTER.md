## 2. Detalle de Riesgos Abiertos y Acciones de Contingencia

### R-01: CI Remota en GitHub Actions Pendiente
* **Causa Raíz:** La política de gobernanza prohíbe terminantemente ejecutar `git push` sin autorización humana explícita.
* **Impacto:** Aunque las suites pasan localmente en Windows con Node 22, la ejecución nativa en Linux (Ubuntu) y macOS en los servidores de GitHub queda pendiente.
* **Contingencia:** Si el CI remoto llegara a fallar una vez autorizado el push, la falla se aislaría en la rama `fix/p0-security-concurrency-hardening` sin afectar la rama `master` ni a ningún consumidor.

### R-02: Deriva de Dependencias Upstream
* **Causa Raíz:** `package-lock.json` no está versionado en Git para mantener la arquitectura de biblioteca agnóstica.
* **Impacto:** Futuras ejecuciones de CI podrían descargar parches de dependencias no probadas.
* **Contingencia:** Si se detecta inestabilidad en una versión upstream, se generará y versionará un `package-lock.json` específico para el CI o se fijarán versiones exactas en `package.json`.
