## 2. Mejoras y Endurecimiento de `.github/workflows/ci.yml` en P1.3

1. **Paso de Verificación Automatizada de SBOM:**
   * Se incorporó el paso `node scripts/generate-sbom.js --validate`, asegurando que ningún build de CI apruebe si el SBOM está desincronizado o no coincide con el tarball calificado.
2. **Preservación y Subida de Evidencias Diagnósticas:**
   * Se añadió el paso condicional con `actions/upload-artifact@v4` (`if: failure()`), el cual recolecta automáticamente:
     * `.work/evidence/`
     * Archivos de bitácora (`*.log`)
     * Reporte de aborto (`promotion_abort_evidence.json`)
3. **Mínimos Privilegios Garantizados:**
   * El workflow mantiene `permissions: contents: read`, imposibilitando escrituras remotas o filtraciones de tokens con permisos de escritura.
4. **Instalación Reproducible:**
   * Mantiene el bloque condicional en shell bash (`npm ci` si existe lockfile, `npm install` si no), protegiendo la ejecución tanto en entornos con lockfile como en checkouts limpios.
